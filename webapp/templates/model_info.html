How OcuSelect combines the models

The two predictions are not merged into a clinical score. Instead, OcuSelect reports their positions relative to the respective experimental dataset medians and places the query into a descriptive activity/permeability profile.

Tanimoto similarity is calculated separately using Morgan fingerprints. The 0.40 and 0.70 similarity categories are display heuristics, not experimentally validated therapeutic cutoffs.

Data sources

Model A uses TGFBR1 (ALK5) IC50 data from ChEMBL (target CHEMBL4439). Model B uses the experimental corneal permeability dataset from QsarDB (record 2010PR1398), which collects measurements from several published studies.

Limitations

Model A was trained only on compounds that were already tested against TGFBR1, so it cannot recognise inactive compounds. If a query is not similar to the training compounds (Tanimoto below {{ '%.2f'|format(similarity_min) }}), the result is marked as low confidence.

Model B was trained on only {{ corneal_n }} compounds with molecular weight up to about 400. Its accuracy is moderate, and larger molecules are outside its training range.

Cross-validation scores can look better than real performance on new chemistry. These results are for research exploration only.
